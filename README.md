# ROI Quant · 科研图像定量与时序分析

**让区域测量有依据，让跨图比较有尺度，让动态变化有轨迹。**

基于 MATLAB 的交互式二维图像定量工具，将 ROI 勾画、背景校正、物理尺度保持、批量统计与时间曲线连接为连续的分析流程。工具起源于磁粒子成像（MPI）研究，也适用于以**单帧灰度 DICOM 或 TIFF**保存的荧光、显微及其他二维标量图像的区域测量。

**DICOM / TIFF · 多形状 ROI · 背景校正 · 跨图物理尺寸保持 · 批量导出 · 时间曲线**

## 值得关注的功能

| 功能 | 可以解决的问题 |
| --- | --- |
| 保留原始定量信息 | DICOM 根据 RescaleSlope / RescaleIntercept 恢复数值；显示窗宽、色图与测量数值分开处理 |
| 灵活的交互式 ROI | 支持多边形、手绘、椭圆、矩形；可移动、编辑和复制单个或整套区域 |
| 背景校正与多指标测量 | 同时查看均值、总和、标准差、面积、背景校正均值与总和，以及工具定义的区域信噪指标 |
| 跨图保持物理尺寸 | 像素间距有效时，按实际尺寸换算 ROI，便于比较不同 FOV 和采集网格 |
| 定量与动态观察联动 | 在分析窗口查看 ROI 时间曲线，也可从已导出的结果单独绘图 |
| 完整的结果导出 | 保存统计表、ROI 会话、掩膜与图像，支持批量处理和后续分析 |

## 可以用于哪些图像

- **MPI**：观察局部信号、背景校正值及跨时间变化。
- **灰度荧光与显微图像**：测量区域强度、背景差异和面积；跨样本比较前应统一采集设置并检查响应范围。
- **其他二维标量图像**：在文件读入、数值映射和单位含义明确的前提下进行区域统计。

当前读取器支持单帧标量 DICOM 和单页灰度 TIFF。RGB、索引色图、多帧 DICOM、多页 TIFF，以及包含额外非线性数值映射的 DICOM，需要先使用适当的读取或预处理方法。彩色伪彩图和截图不能代替原始定量图像。

## 开始使用

### 环境

MATLAB 与 Image Processing Toolbox。代码以 MATLAB R2024a 为开发环境；其他版本需核对图形界面和 ROI 函数兼容性。

### 启动交互式分析

下载仓库后，在 MATLAB 中将工具目录设为当前文件夹：

```matlab
addpath(pwd);
app = mpi_roi_app('你的图像目录或DICOM文件完整路径');
```

也可以打开 `start_mpi_roi.m` 并运行。原始程序保留了示例默认路径；跨电脑使用时，建议显式传入自己的图像目录。

典型流程：**载入图像 → 勾画目标和背景 ROI → 核对位置与尺度 → 查看统计和曲线 → 保存或批量导出。**

### 从导出结果绘制时间曲线

```matlab
[data, outDir] = plot_mpi_timecourses('你的导出结果目录');
```

目录下放置以时间命名的结果子文件夹，例如 `033_45min`，每个时间点包含 `roi_statistics.xlsx` 或 `roi_statistics.csv`。不同时间点应保持 ROI 名称一致。`start_mpi_timecourses.m` 中的示例目录可按需要修改。

## 数值定义

设目标 ROI 的有效像素数为 `N`，背景有限像素均值为 `B`：

```text
Mean          = Sum / N
CorrectedMean = Mean - B
CorrectedSum  = Sum - N × B
SNR           = CorrectedMean / BackgroundSD
```

- 原始统计保留零和负值，排除 NaN / Inf；不自动做逐图最大值归一化。
- `Sum` / `CorrectedSum` 为像素求和，未乘像素面积；跨采集网格比较时应核对其可比性。
- `Area_mm2` 来自有效的像素间距信息；缺少间距时不推测实际尺寸。
- 阈值相关统计与全 ROI 统计分别报告，具体字段见阈值说明。
- 物理尺寸换算不等于解剖配准，粘贴或批量套用后仍需核对区域位置。
- 不同模态的灰度含义不同；未完成相应标定时，结果不能直接解释为铁质量、分子浓度或跨模态等效信号。
